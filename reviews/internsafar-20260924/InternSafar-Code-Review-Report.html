2. FINDINGS (VERIFIED)

IP-SEC-001 CRITICAL Security

Unauthenticated /api/ip/bootstrap mutates SuperAdmin roles and schema

File & Location: src/app/api/ip/bootstrap/route.js:4-11

Root cause
POST has no requireSession, cron secret, or env gate. ensureIpBootstrap can promote/demote SuperAdmin roles and run schema ensures.
Impact
Any anonymous caller can trigger privileged bootstrap against the shared Neon DB used by local/Vercel.
Evidence
export async function POST() {
  const result = await ensureIpBootstrap();
  return NextResponse.json({ ok: true, ...result });
}
Remediation
Require SuperAdmin session or IP_ALLOW_BOOTSTRAP=1 / deploy secret; remove public client fire-and-forget calls from sign-in pages.

Pattern: AUTHZ-MISSING-GATE · Confidence: High

IP-SEC-002 CRITICAL Security

Employer can open a message thread to any candidate userId (IDOR)

File & Location: src/app/api/ip/messages/threads/route.js:76-120

Root cause
Candidate path validates application+employer; employer path accepts arbitrary otherUserId.
Impact
Employer may create threads to private candidates; combined with file access via thread linkage this can expose resumes.
Evidence
if (!isEmployer) { /* application ownership check */ }
// employers: no ownership check on otherUserId before INSERT thread
Remediation
Require owned internship + application (or explicit searchable invite) before employer thread create.

Pattern: IDOR-MISSING-OWNERSHIP · Confidence: High

IP-CORR-002 HIGH Correctness

Application points debit is not conditional (TOCTOU overdraw)

File & Location: src/app/api/ip/candidate/applications/route.js:160-185

Root cause
Unlike chargePublishPoints, apply debit does not use WHERE points >= cost inside the lock.
Impact
Concurrent applies can drive balance negative while creating applications.
Evidence
