Description

Root Cause & Concrete Impact
POST has no requireSession, cron secret, or env gate. ensureIpBootstrap can promote/demote SuperAdmin roles and run schema ensures. Any anonymous caller can trigger privileged bootstrap against the shared Neon DB used by local/Vercel.
